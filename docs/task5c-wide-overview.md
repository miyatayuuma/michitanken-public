# Task⑤-C1b：広域俯瞰の固定GPU予算（PUBLIC架空地理のみ）

## 切替方針

- 3×3・9タイル以下：これまでの3Dタイル俯瞰を保持。Task⑤-Bの道路DEM追従・河川・衝突判定は変更しない。
- 9タイル超：全域は固定解像度の地形メッシュ＋水域・道路・建物ラスターレイヤーで描画する。
- レンダラから見た俯瞰の全域表示は1グループ・共有地形ジオメトリ・固定テクスチャ3枚。通常の詳細3Dタイルはカメラの注視位置周辺を別途ストリーミングする。
- 低解像度の背景地形は8m低く描画し、近距離の詳細タイルを重ねたときに優先表示されるようにする。データ上の標高は変更しない。
- 俯瞰から歩行へ戻った時点で背景アトラスのWebGLリソースを破棄する。

## リソース予算・データ保護

| 制約 | 値 |
|---|---|
| 全域ラスタ画像 | 1536×1536px ×3枚（水／道路・鉄道／建物） |
| 地形の総セル目標 | 3600 |
| 5×5での全域地形 | 12セル／タイル辺、7200三角形 |
| 対応タイル数 | 最大900枚まで（これを超えるmanifestは意図的に拒否） |
| リクエスト同時数 | 最大2（scanAll） |
| 遠方GPUマウント | 不要（scanAll はスナップショットを読み取り、素材化後に破棄） |
| PRIVATE地理情報 | PUBLICのテスト・Actions・スクリーンショットに含めない |

定量値は頂点・テクスチャの予算上限であり、実端末のGPUメモリ使用量やFPSの実測を表さない。タイル枚数に比例して原データの取得量・処理時間は増える。水面アニメーションや詳細な建物外形は遠景ラスタには再現しない。ズーム時は周辺の通常3Dタイルを表示する。広域アトラスは地理上の権利・通行許可・行政境界を示すものではない。

## PUBLIC CI受入

- 架空5×5：全25枚の遠景表示を固定アトラスへ変換し、実GPU詳細タイルを25枚保持しない。
- 同時取得上限・キャンセル・返却後のCPUキャッシュ保持なし・GPUリソース破棄を単体テスト。
- Chromiumモバイルヘッドレスで5×5全域表示、歩行復帰、WebGL描画統計を確認し、架空画像のみartifact保存。
- 架空3×3：従来の9タイル通常3D俯瞰の回帰チェック。

PUBLIC CIがPASSしても、実地理の河川・道路・建物・端末性能は別途PRIVATE組立と手動受入が必要。PRIVATE GitHub Actionsは実行しない。

## 既知の限界とC2への条件

大きなタイル数では画像縮尺に対し道路が細くなり、文字や詳細な建物形状は表現できない。すべての地理スナップショットを広域表示開始時に読み込むため、実データの通信遅延・欠損・取得失敗を実地理結合後に検証する。

Task⑤-Cの実地理増築は別PR・別受入。既存9タイルの原本保全、隣接辺のDEM・道路・河川・当たり判定・操作UX、Firebase本番確認が必要。
