# MT-01 / MT-02 — 色彩と公共ランドマーク

PUBLIC基準: PR #10 `ad377350a9514c8151b49ed98f5f899da5a9e00a`。PR #8（植生）と #9（GC201）の双方を含む統合作業ブランチへ積み上げる。既存PRやmainの変更、Firebaseデプロイは行わない。

## 色彩

- 壁8色・屋根8色。OSM建物IDを優先し、IDのない合成データは正規化した世界座標の頂点集合を使う。壁と屋根に独立したhashを用いる。
- 壁・屋根の各一括Mesh、既存の形状・法線・当たり判定を保持し、linear RGB頂点カラーを追加。通常/遠景の建物と固定1536pxアトラスは同じ関数を使う。アトラスの建物層は詳細屋根と同じ拡散照明を使う。
- 草・花・低木・岩は元マテリアルに0.90〜1.00のlinear RGB倍率をinstanceColorで乗算。樹木とテクスチャ付きモデルは除外。配置/スケール/姿勢は変更しない。
- `?colors=off&natureColors=off&markers=off` で従来の色と構造を比較できる。個別の無効化も可能。

## POI

`lib/poi.mjs` がID・カテゴリ・タイル所有・世界座標・表示・将来用タグ・出典を検証し、不変のID検索/タイル検索を提供する。`src/poi-markers.js` はデータから独立した表示層。保存進捗やスポーンは今回実装しない。

`public/data/pois.json` はschema 1、sourcesとpointsを持つ。positionは **[世界X m, 絶対標高m, 世界Z m]**。heightを登録時に検証するので、遠方タイルの描画が未常駐でも同じ位置を表示できる。境界所有は `tileAtPosition` の半開区間と一致する。地形/マニフェストを再生成する場合は地点データも再検証する。

各pointは `id/category/name/tileId/position/marker/biomeTags/eventTags/source` を持つ。markerは `enabled/priority(0〜10)/range(50〜1200m)`。sourceはsources内ID、原本feature、確認URLを持つ。名前はtextContentで表示する。未知フィールド・不明出典・不正座標・ID重複は拒否。将来のイベント実装は地点IDを参照するが、マーカー位置を安全なスポーン位置や施設入口と解釈してはならない。

- 公園、神社/寺院、橋、水辺、公共施設/広場の5カテゴリ。アイコンと形状も変える。
- 歩行は個別range以内・最大12件、俯瞰はPC24/モバイル18件。レジストリ上限512件。
- 接近65m以内、俯瞰では低い視点のときだけ短い名称を表示。アイコンと名称の矩形を同時に重なり判定し、priority/距離/IDで決定的に間引く。HUD・移動/走行ボタンも回避する。
- DOM要素のプールを使い、追加WebGL draw call/triangle/textureは0。全体をpointer-events:noneとし、キー・タッチ・ゲームパッドイベントを登録しない。
- タイルの描画ライフサイクルと独立したレジストリなので、LODやGPUタイル解放でIDが重複・消滅しない。
- 404/未設置は地点なしで継続。不正データは警告と `data-poi-error` に出し、任意レイヤーとしてゲーム自体は継続する。

PUBLICに実地点・実座標は入れない。デモ地点5件は架空、素材を使わない自作SVGピクトグラム。PRIVATEデータは独立PRで保管し、既存保護マニフェストで組み立てる。

## 検証

`npm test` と `npm run build`。`scripts/browser-mt01-mt02.mjs` は架空5×5でPC/モバイル・色・地点所有・間引き・再読込・入力透過を確認する。既存browser-wide-overviewとbrowser-player-spriteも併用する。PUBLIC CIには架空データのみを使う。

`?test=1` の `__michiDebug.poi()` は表示矩形/ID/元の世界座標、`renderStats()` はgeometryBytes・heapBytes・markersと既存のGL統計を返す。geometryBytesはシーンから参照するTypedArrayバッファのbyteLength（GPU実消費全体ではない）。heapBytesはChromium依存で、GCタイミングによって変動する。

実地理の性能値と受入結果はPRIVATEレポートを正本とする。SwiftShader結果は実機のFPSやメモリを保証しない。Windows GC201/Android実機での色・マーカー可読性・操作・実GPU負荷は未確認。
