# 共通UI仕様 v0.1 — 視覚受入待ち

## 色トークン

| Token | HEX | 用途 |
|---|---|---|
| paper | #fff5df | 不透明な文字・操作パネル |
| ink | #303b35 | 文字・基本アイコン |
| edge | #71644e | 操作枠・地図枠 |
| action | #245b4d | 実行可能・採集・開放ワープ |
| focus | #9b4b25 | キーボード/パッドfocus・選択中の地点 |
| quiet | #706b60 | 補助ラベル |
| disabled | #d7cfbd | 無効背景、文字#666155 |
| error | #923e39 | エラー枠・失敗記号 |

紙面上の文字は不透明背景とセット。背景フィールドの上に色文字だけを浮かせない。色に加え輪郭・下線・旗・チェック・エラー記号で状態を識別。数値コントラストはreview.md。地図の草・水・雲は情報色で操作色を兼ねない。

## 形状・状態

基準グリッド4px。角は12/9/14/8pxの固定した軽い不規則性、線1.5px、24px viewBoxアイコン線1.8px、丸cap/join。文字はsystem-ui/Noto Sans JPフォールバック、本文16px、操作ラベル16px、補助12px以上。文字に手描きフォントを使わない。ノイズテクスチャ、ランダム線変動、絵文字は不採用。

- 通常: paper/ink、edge枠。
- hover: 枠をinkへ。意味変化をhoverだけに依存しない。
- 選択中: action面/paper線＋短い下線、aria-pressed。
- focus: focus色3px外枠＋3px offset。選択と独立して表示。
- 押下: 2px沈み。release/cancel/blurで必ず復元。
- 無効: disabled背景/指定文字、押下不可、disabled属性。opacityだけで表さない。
- busy: 同じ位置で静止した砂時計線画、再決定禁止。終了後focus復元。
- 失敗: error枠＋感嘆符＋短い必要文。常設エラーをタイマーで消さない。

## 素材の決定

UIアイコンは本プレビュー内の独自SVGパス1系統（map/close/plus/minus/menu/cat/rabbit/hand/flag/run/tree/check）。外部素材の転用なし、追加ダウンロード・Webfontなし。既存のlib/poi.mjsのSVG方式を拡張する方針。後続では同じ24px/1.8px規約で全施設種と砂時計・エラーを補完する。異系統アイコンの追加は禁止。

既存Kenney Cartographyはsrc/assets/cartography/provenance.jsonとLicense.txtで作者・CC0・改変なしPNGを確認済み。再利用可能だが、UIのPNGと線画混在を避けるため**UIへの採用は終了し、同じ線画へ置換**。本タスクでは既存素材を削除しない。世界内のモデル・猫うさぎ原画は加工対象外。プレビュー内の仮キャラは公開可能なSVGダミーで、本番原画の変更案ではない。

## レイアウト

| 対象 | 余白 | 操作 |
|---|---|---|
| PC 1280〜 | 端16px＋safe-area | 左上地図・2キャラ、右上コンパス・メニュー。タッチ非表示 |
| スマホ縦 360〜430 | 端12px＋safe-area | 同じ上端。下部左116px移動、右68px走る、上64px採集 |
| スマホ横 740〜 | 端12px＋safe-area | 移動96px、走る68px、地図操作帯80px。中央を空ける |
| コントローラー | PCまたはモバイルと同じ端基準 | 接続だけでタッチを消さず最後に使った入力で変更。操作時だけ短いglyph。focus 3px |

全buttonの実効領域44px以上、通常48px、スマホ46px。8px以上の隣接間隔を原則とし、キャラ2択内部のみ4〜6px。押下領域を重複させない。探索中中央60%×50%に常設パネルを置かない。地図中は探索HUDを非表示。地図上部90pxと下部操作帯を確保し、選択カードが縮尺・＋/−と重ならない。地名は2行まで、超長文は選択カード内で折返す。320px・200%文字拡大時は上部2段化、パネルscrollを後続で実装検証。

親DreamCoreの戻る・音量UIを予約領域として計測してから配置。iframeのviewportは親の操作帯を除いた領域。子にサイトへ戻る常設ボタンを追加しない。埋込では親の共有音声UIへ委譲。メニュー案は単独起動用。プレビューの親フレーム非再現を統合PASSと誤記しない。

## 効果の共通仕様

| 状態 | 形・時間 | 制約 |
|---|---|---|
| 操作可能 | 宝物の根元に紙縁付き深緑の静止輪、遠方は小さな菱形 | 視界内・安全距離内、最大3、常時点滅なし |
| 最寄り対象 | 1つだけ輪を太く、上に小さい菱形 | 距離＋視認性＋採集可能ID。動物・既採集は対象外 |
| 選択地点 | 錆色二重輪＋選択カード | 地図pan・対象変更で確認を解除 |
| 採集成功 | 根元から短い線3本＋SE、450ms | 1回、長文なし |
| 地点発見 | 紙色輪が1回広がる＋SE、650ms | 同時最大1、再訪で再発火しない |
| ワープ成功 | 紙色フェードout/in各120ms、到着輪350ms＋SE | 位置確定後だけ成功、busy中は入力遮断 |
| 操作失敗 | エラー記号と短文、SE1回 | 画面揺れなし、移動を実行しない |

prefers-reduced-motionでは拡大・移動・フェードを省略し、静止輪/チェックを350〜700ms。成功記号の消去以外に無限animationは使わない。低性能モードは静止輪のみ。効果用の全画面postprocess・追加シャドウ・常設RAFを増やさない。SEはDreamCore設定/ミュート継承、250ms以上の再発火間隔、同時最大1。音だけで成功を知らせない。
