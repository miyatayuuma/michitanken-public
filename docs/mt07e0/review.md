# 視覚セルフレビュー

## 検証

Chromium headless shellで9画面×3viewport（1440×1000、390×1000、844×390）を実描画。横画面はゲーム領域を360px高にし、プレビュー用ナビは領域外にある。qa.jsonのoverflowはページ横はみ出し、smallTargetsはゲーム内buttonの44px未満、errorsはJS例外。画像は全ページキャプチャであり、ゲームのviewportだけをスクロールなしで再現する本番UIではない。

地図＋ボタンで2倍、地点選択→別ボタンで成功模擬、うさぎへの選択切替も3viewportで確認。スクリプトverify-preview.cjsを保存。PlaywrightとChromium、日本語フォントが必要。今回Noto Sans CJK JPを検証環境だけに配置（https://github.com/notofonts/noto-cjk）。フォントファイルを成果物に同梱しない。

初回の目視で日本語欠落、横画面幅固定、仮キャラ黒塗りを検出し修正後に再描画。PC宝物・スマホワープ・横タッチを目視確認。必須6画面をコンタクトシートで比較し、拡大案の選択地点が下端へ寄る問題を修正した。全27枚の個別目視は実施していない。

## コントラスト計算

WCAG相対輝度式、sRGB→線形変換で計算。paperに対し ink 10.75:1、edge 5.33:1、action 7.23:1、focus 5.65:1、quiet 4.89:1、error 6.52:1。disabled文字/背景3.98:1（無効状態専用）。本文用色は4.5:1以上、輪郭は3:1以上。これは指定色同士の計算であり、実地形の全フレーム検証ではない。

## 評価と限界

- 紙面・固定不規則角・線画・状態色を統一。世界内の原画やモデルは変更なし。
- 中央を空け、採集は静止輪＋菱形、短い成功記号。採集対象以外に輪を付けない本番ロジックは後続。
- 地図操作帯とワープ確定カードを分離。縮尺や＋/−をカードで塞がない。スマホの地点には透明な44px相当のhit円を追加し、見た目と操作範囲を分離。
- スマホ横の上部と下部操作を離した。ノッチsafe-areaはCSS規則のみ、実機検証は未実施。
- アクセシビリティ: 名前付きボタン、選択aria-pressed、focus-visible、live status、reduced-motion。完全なdialog focus trapや200%文字配置は後続受入。
- 深緑の宝物輪は白い紙縁を伴う。最終3D地形での認知しやすさ、実機GC201、7歳児の理解は未確認。
- DreamCore親との領域予約・音声委譲は仕様化。親付き実画面の競合検証は未実施、PASSとしない。
- この案の地図は架空図。現実の密度/25タイル/22地点は用いていない。実地理での重なり検証はPRIVATEローカル作業として後続へ。
