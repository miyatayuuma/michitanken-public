# MT-04–06 exploration implementation

Depends on PUBLIC #12 `73fd50ed582df4f5bb9752f640a0fea5dc7c125d`. All prior sprite/5x5/gamepad/marker dependencies are retained. Real geography, derived real placements, user artwork and screenshots belong only in PRIVATE.

## Runtime contract

The v1 dry-ground registry lives in `lib/exploration.mjs`. The offline generator revalidates every MT-03 candidate with the original global terrain/OSM/vegetation index, selects globally in deterministic hash order, maintains 24m inter-object spacing across tile edges, caps the entire map at 1400, then writes one compact JSON per tile. The old MT-03 generic category examples are superseded by explicit registry habitat weights; geometric safety, radius 1.5m, slope and dry-ground constraints are unchanged. No water-surface spawning is added.

The field streamer owns tile lifetimes. Async spawn fetches have cancellation and token checks. A 65m radius and nearest-12 limit (nearest-6 on <=2GiB reported device memory) bound the renderer. Updates run at 10Hz / 5Hz. The two new models share one identical CC0 colormap texture. Cloned Skeleton GPU resources are explicitly disposed on removal. Models are shared and only cloned for nearby inhabitants. All field objects disappear in overview; acquired treasures are filtered before re-instantiation. `?exploration=off` supports comparison. `?test=1` exposes deterministic spawn snapshots through `__michiDebug.exploration()`; no geographic data is included in PUBLIC diagnostics. No long-distance creature/treasure markers are added.

Bird: approach within 5m raises it above ground, retreat beyond 10m returns it. Caterpillar: small bounded motion slows when approached; it returns when the player retreats. Both stay within the approved 1.5m footprint. Existing bees/ducks remain in their established renderer, with a shared discovery callback and existing 7-object cap; duck water-height policy is retained. No movement pathfinding is introduced.

Pickup: touch button shown only within 4.5m, E, standard gamepad X (button 2). Records: touch button, J, standard gamepad Y (3). B / Escape closes records. A still switches walking/overview. RT is unchanged. Parent A messages are not duplicated by local sampling. Journal pauses player movement and local look input. Sound is not added, so existing mute/volume policies remain intact.

Records and fixed-treasure IDs are separate storage entries. Only schema, known species counts, and sorted opaque acquired IDs are stored; no positions, route sequence, timestamps or identity. Animals can be encountered again; each fixed treasure can be collected once per browser save, with no timed respawn. Invalid/unknown values are discarded and counts bounded. Storage errors do not crash play; a save-failure message is shown. Deleting site data resets this local game, and cannot be prevented by a local-only implementation.
