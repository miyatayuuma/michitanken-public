# みちたんけん — 公開ゲームエンジン

3D地形・道路・建物の描画、歩行操作、タイル読み込み、衝突判定の開発用リポジトリです。

## データとプライバシー

この公開リポジトリの `public/data/` は、実在の場所とは無関係な**架空のテストデータ**です。非公開の実地理スナップショットや、それに依存する監査ログ・テストは収録していません。地形・道路・建物は合成サンプルであり、現実の通学路・位置履歴を示すものではありません。

元の非公開リポジトリのGit履歴、Issue、PR、Actions実行履歴は引き継いでいません。既存の本番デプロイ経路もこの公開版には設定していません。

## 開発

```sh
npm install
npm test
npm run build
npm run dev
```

公開CIは一般的な単体テストとビルドのみ実行します。実地理データに依存する受入検証は含みません。

このコードは公開されていますが、現時点で第三者への利用・再配布ライセンスは付与していません。
